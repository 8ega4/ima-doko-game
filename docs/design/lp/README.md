# LP design

「いま、どこ？」のルール、段階的な難易度、結果共有を、プレイ前に短時間で理解できるランディングページです。

## Concepts

- `01-hero-concept.png`: ルールとプレイCTA
- `02-howto-concept.png`: 見る、追う、当てる
- `03-difficulty-concept.png`: 5ラウンドの速度上昇
- `04-result-cta-concept.png`: 採点、共有、最終CTA

## Design system

- Background: `#020713`
- Field: `#031426`
- Text: `#f7f3ea`
- Cyan: `#25d9ff`
- Coral: `#ff654f`
- Yellow: `#f4f700`
- Japanese type: Noto Sans JP Variable
- Numbers: Roboto Mono Variable
- Geometry: 角を切ったフレームとボタン、開いたレイアウト、軌道をつなぎに使う

## Fidelity ledger

| 比較点 | コンセプト | 実装結果 |
| --- | --- | --- |
| ヒーロー | 左に2行見出し、右にゲーム面 | 同じ構成で、右側を実際に動くCanvasへ置換 |
| ルール説明 | 一本の軌道上に3ステップ | デスクトップは横軌道、スマホは縦軌道 |
| 難易度 | 上昇線上に5ラウンド | 実際の倍率定数を参照して表示 |
| 結果 | 428/500、5問、共有先 | 実ゲームの称号「物理学者」と、実際に操作できる5種類の共有ボタンを表示 |
| CTA | 蛍光イエローの単一主CTA | ヒーロー、ヘッダー、最終部からゲームTOPへ遷移 |
| レスポンシブ | モバイルで縦に継続 | 320px、390px、1440pxで横溢れなし |
| モーション | 軌道をページ全体のつなぎに使う | 軌道を描くオープニングとスクロール連動の段階表示を追加 |
| ヘッダー | ページ上部のナビゲーション | 画面上部へ追従し、実測高をアンカー位置へ反映 |
| フッター | ブランドでページを締める | ヘッダーと同じ3項目のページ内メニューを追加 |

## Intentional deviations

- コンセプトのサンプル称号は、実ゲームに存在する「物理学者」へ修正。
- 既存機能を維持するため、音声ボタン、じっくりモード、自己ベストをLP内に残した。
- ゲームプレビューは静止画像ではなく、既存の物理・描画処理を使うCanvasにした。
- LPのCTAは直接ゲームを始めず、既存のゲームTOPへ移動する。
- 外部GitHubリンクはLPに掲載しない。
- `prefers-reduced-motion`ではオープニングとスクロール演出を無効化する。
